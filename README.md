# quiz-game
A True or False quiz game that tracks your score

Features
- 10 Questions randomly selected from a Trivia API
- Facts are displayed on UI and user must click True or False
- If user is correct, fact tile lights up green. If not, fact tile lights up red. Screen updates to next question.
- Score is recorded and displayed.

Technologies
- Python
- Libraries: Requests, Tkinter, HTML

- UI Design
- Object-Oriented Programming
